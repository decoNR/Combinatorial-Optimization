\begin{solution}
Below is the integer program requested.  

\begin{alignat*}{3}
  \text{Minimize} \quad
  % & \iprodt{c}{x} &
  & c^{\transp}x &
  \\[0pt]
  \text{subject to}\quad
  & x \in \set{0,1}^{E}&&
  \\[0pt]
  & x(\delta(v)) \geq 1, &&
  \qquad \text{for each }v \in V,
  \\[0pt]
  & x(\delta(S)) \geq 1, &&
  \qquad \text{for each } S \subseteq V \text{ such that } \emptyset \neq S \neq V
\end{alignat*}

The above formulation uses the variable $x$, where each entry is associated with an edge $e \in E$. The entry of $x$ correspondent to $e$ is suposed to be equal to 1 if $e$ is on a spanning tree, otherwise it will be 0. 

Initially it is important to mention that a spanning tree it is a tree (acyclic) which the set of vertices of this tree is equal to $V$.

The first set of constraints $x(\delta(v)) \geq 1$ enforces that each vertex $v \in V$ is an end of at least one of the edges of the spaning tree. The second set of constraints $x(\delta(S)) \geq 1$ guarantee that the graph generated by set of edges that are correct answers for the problem is connected (technique used in class). 

Given that, the set of edges that will have correspondent $x$ entry equal to 1 is associated with a connected graph that has set of vertices equal to $V$. By associated graph, I mean the graph that has set of edges equal to set of edges that will have correspondent $x$ entry equal to 1 and set of vertices equal to the set of all vertices that are an end of an edge that is an elment of the set of edges. Given that, the only constrain that is not adressed yet is the fact that the associated graph need to be acyclic because it is a spanning tree. This is not a problem because, as we are minimizing $c^{\transp}x$, a cycle will never be in our answer. This is true and trivial because, if there is a cycle on the associated graph, you can remove an edge that is on this cycle and the associated graph will continue to be connected, otherwise this edge would not be in a cycle by definition. Also, as every vertex in a cycle is an end of two distinct edges, the set of edges remains equal to $V$ when you remove one edge from the cycle. Thus, $c^{\transp}x$ gives the desired answer.
\end{solution}

\begin{solution}
  Below is the integer program requested.  

  \begin{alignat*}{3}
    \text{Maxmize} \quad
    % & \iprodt{c}{x} 
    & \mathbbm{1}^{\transp}e &
    \\[0pt]
    \text{subject to}\quad
    & v \in \set{0,1}^{V}, e \in \set{0,1}^{E}&&
    \\[0pt]
    & v_u + v_w + e_{uw} \leq 2, &&
    \qquad \text{for each } \set{u,v} \in E,
    \\[0pt]
    & v_u + v_w - e_{uw} \geq 0, &&
    \qquad \text{for each } \set{u,v} \in E,
    \\[0pt]
    & v_u - v_w - e_{uw} \leq 0, &&
    \qquad \text{for each } \set{u,v} \in E,
    \\[0pt]
    & v_w - v_u - e_{uw} \leq 0, &&
    \qquad \text{for each } \set{u,v} \in E,
  \end{alignat*}
  
  The above formulation uses the variable $v$, where $v_u$ is supposed to be 1 if the vertex $u$ is in a shore of the cut and 0 otherwise. It also uses the variable $e$, where the entry $e_{uw}$ is supposed to be 1 if the edge $\set{u,w}$ is in the cut. 
  
  For this problem I wrote the constrains based on the valid scenarios. An edge $\set{u,w} \in E$, which has ends $u$ and $w$, is in a cut if and only if exactly one of those vertices are in a shore of the cut. To clarify, my formulation accepts values of all possible shores and the cuts associated with each shore.
  
  Now I will explain better each constrain. The top constrain $v_u + v_w + e_{uw} \leq 2$ invalidates the scenario where the 3 variables are 1. The second constrain $v_u + v_w - e_{uw} \geq 0$ does not allow $v_u$ and $v_w$ to be 0 and $e_{u,w}$ to be 1. The third and fourth constrains inevalidate the scenario where only 1 vertex of the edge is in a shore but the edge is not in the cut. It is important to mention that the third and fourth constrains are symetric and I just add both because edges are an unordered pair. More important than that, all valid scenarios satisfy all the constrains.
  
  The sum of all entries of $e$ that are equal to 1 is the number of edges in a cut. As we are maximizing this sum, we will have the maximum size of a cut of $G$.
\end{solution}


\begin{solution}
  I will prove that $\mathcal{H}^{\text{min}}$ is a clutter  and $B^{\text{min}}$ is its blocker. From exercise 11 of assignment 0, we have that $\mathcal{H}^{\text{min}} = \paren{\mathcal{H}^{\text{min}}}^{\text{min}}$, then $\mathcal{H}^{\text{min}}$ is a clutter. For the other part, I need to prove that $b\paren{\mathcal{H}^{\text{min}}} = \mathcal{B}^{\text{min}}$. Let $B\paren{\mathcal{H}^{\text{min}}} \coloneqq \paren{V, \set{K \subseteq V: K \text{ is a vertex cover of } H^{\text{min}}}}$, which is the same definition as the blocker definition but without the min involved. First I will prove that $B(\mathcal{H^{\text{min}}}) = \mathcal{B}$ by showing that $B(\mathcal{H^{\text{min}}}) \subseteq \mathcal{B}$ and that $B(\mathcal{H^{\text{min}}}) \supseteq \mathcal{B}$.
  
  A set of edges $T \subseteq E(G)$ is not in $B(\mathcal{H^{\text{min}}})$ if it does not contain any edges of an odd minimal circuit $c \in G$ (by definition all circuits are minimal). For $T$ to be in $\mathcal{E}(\mathcal{B})$, one has $E(c) \subseteq \delta(S)$ for an $S \in \mathcal{P(V)}$. That is impossible because $S$ could not have neighboring vertices that are in $c$. Supose $S$ contain an arbitrary vertex $v \in E(c)$, then it could not have the neighbors of $v$ but it must have the neighbors of the neighbors of $v$ that are in $E(c)$ because otherwise you would have one missing edge in our desired $\delta(S)$. Pick a direction and start choosing all the necessary vertices using the previous criteria. As $c$ is an odd circuit, at the end you would have to pick a vertex $u$ that is a neighbor of $v$, which is a contradiction. Given that every non-edge of $B(\mathcal{H^{\text{min}}})$ is a non-edge of $\mathcal{B}$, then $\mathcal{B} \subseteq B(\mathcal{H^{\text{min}}})$.  

  On the other hand, if $T \subseteq E(G)$ is in $\mathcal{E}(H^{\text{min}})$, then $G-T$ is a bipartite graph $(A,B)$ because it does not have odd circuits. This is true because for even circuits you can easily have a bipartion (neighboring vertices are in different partitions). If the subgraph is not a circuit you also can have neighboring vertices in different partions because if you start in the root vertex you will never have an edge that one end is a previous vertex in the path and you will go through all the vertices in the path. Then, if you choose $S = A$, we have  $\delta(S) = E(G) \setminus T$. Given that $E(G) \setminus \delta(S) = T$. Thus, $T \in \mathcal{E}\paren{\mathcal{B}}$, and therefore $\mathcal{B} \supseteq B(\mathcal{H^{\text{min}}})$.
  
  Given the discussion above $B(\mathcal{H^{\text{min}}}) = \mathcal{B}$. By definition it, is trivial that, if $B(\mathcal{H^{\text{min}}}) = \mathcal{B}$, then $(B(\mathcal{H^{\text{min}}}))^{\text{min}} = \mathcal{B}^{\text{min}}$. Thus, $b\paren{\mathcal{H}^{\text{min}}} = \mathcal{B}^{\text{min}}$.
\end{solution}
